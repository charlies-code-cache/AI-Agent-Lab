How to Use

Welcome to my trading card website! This page explains how to navigate and use the website, along with all of the accessability features we have.

Still stuck? Check out our support page.

Tutorial & Walkthrough

Follow these steps to learn how to use the website.

  1. 1. Review the Pop Up

    When you open the card, a short welcome pop-up explains what the page does. Click Let's Go to close it. You can also click Read the Guide First to come here.

    Keyboard Shortcuts: Tab moves between buttons, Enter picks one, Esc closes the pop-up.

  2. 2. Open the Card

    The card lists Charlie's name, major, level, and special ability. Press Play to start open the game window.

    Keyboard Shortcuts: Tab moves between buttons or Enter picks one.

  3. 3. Press Start

    Press Start when you're ready to start the game!

    Keyboard Shortcuts: Tab moves between buttons or Enter picks one.

  4. 4. Play the Game

    Click or tap the big "Click" button as many times as you can before the timer hits zero. Score at least your level target to win. A new best score raises the target by one, so the next round is a little harder.

    Keyboard Shortcuts: Space or Enter on the "Click" button.

FAQs

Can I play without a mouse?

Yes. Tab moves between buttons and Enter picks one. In the game, you can tap Space or Enter instead of clicking. Esc closes any pop-up.

Does it work on a phone?

Yes. Tap instead of clicking.

Does it work with a screen reader?

Yes, all interactive elements are properly labeled with alt text for screen reader accessibility.

Is there Alt Text for images?

All images have alt text for screen readers.
